# Standalone Architecture

## Recommended production topology

`rdp.iniakpothompson.com` is a standalone application and Git repository. It does not import code from, or share a database with, `iniakpothompson.com`.

```text
Internet
   |
   v
https://rdp.iniakpothompson.com
   |
   v
Plesk nginx / TLS
   |-------------------------------|
   |                               |
/api/v1/*                      all other paths
   |                               |
   v                               v
FastAPI                         Next.js
127.0.0.1:8010                 127.0.0.1:3010
   |
   v
Standalone MariaDB database
```

The main website remains linked in both directions:

```text
iniakpothompson.com
  -> public navigation/footer -> rdp.iniakpothompson.com
  -> admin navigation         -> rdp.iniakpothompson.com/admin

rdp.iniakpothompson.com
  -> programme branding and main-site links -> iniakpothompson.com
```

## Why the database and authentication are separate

This is intentional isolation. An RDP deployment or migration cannot modify the main website database. The standalone application has its own administrator and participant authentication. This avoids tight coupling between the main CMS and the programme platform. Single sign-on can be added later as an explicit identity integration if required; it is not necessary for the programme to be correctly linked to the main site.

- Internal health: `http://127.0.0.1:8010/health`
- Public health through Plesk: `https://rdp.iniakpothompson.com/api/v1/health`
- Public RDP API prefix: `/api/v1/rdp`

## Payment architecture

The invoice/enrolment layer is provider-neutral. Paystack and Stripe are adapters. Gateway credentials are entered through the administrator UI, encrypted in the RDP database with `CREDENTIAL_ENCRYPTION_KEY`, and never returned in plaintext after storage.

Production webhook URLs:

- Paystack: `https://rdp.iniakpothompson.com/api/v1/rdp/public/payments/webhooks/paystack`
- Stripe: `https://rdp.iniakpothompson.com/api/v1/rdp/public/payments/webhooks/stripe`

Callbacks are generated by the application using the same public origin.

## Repositories

Use two independent Git repositories:

1. Main website repository: `iniakpothompson.com`
2. Programme repository: `ungozu-rdp`

The supplied main-site patch contains only cross-site navigation links. Do not re-add the old integrated RDP backend, migrations, or `/rdp` pages to the main repository after adopting the standalone architecture.
